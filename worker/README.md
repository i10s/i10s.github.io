# ifuentes.net agent endpoints (Cloudflare Worker)

A small Worker that runs on a few paths of `ifuentes.net`. GitHub Pages keeps serving everything else.

| Path | What it does |
| --- | --- |
| `/api`, `/api/*` | Read-only REST API (`src/api.js`): `/api` (index), `/api/profile`, `/api/resume`, `/api/now` (JSON with the Markdown text and its `last_updated`), `/api/posts` (`?topic=`, `?lang=`, `?limit=`) and `/api/posts/{slug}`. CORS `*`, `GET`/`HEAD`/`OPTIONS`; errors are RFC 9457 `application/problem+json` (400, 404, 405, 502). Described by `/openapi.json`. |
| `/mcp` | Read-only [MCP](https://modelcontextprotocol.io) server: Streamable HTTP, stateless, no authentication. Built with `createMcpHandler` from the [Agents SDK](https://developers.cloudflare.com/agents/model-context-protocol/apis/handler-api/). Tools `get_profile`, `get_resume`, `get_now`, `get_blog_posts` (the same documents as resources) and `get_blog_post` (`slug`). |
| `/a2a` | [A2A](https://a2a-protocol.org) agent, JSON-RPC 2.0 `message/send`. Deterministic: it picks the right document and returns it verbatim, so it never invents facts. |
| `/ask` | [NLWeb](https://github.com/nlweb-ai/NLWeb) v0.55 (`src/nlweb.js`), list mode: `GET ?query=` or `POST {"query":{"text":…}}`; `streaming=true` or `Accept: text/event-stream` for server-sent events (`start`, `result`, `complete`). Ranks the documents with the A2A keyword rules and the blog posts by the words of their title and summary; no generative AI. |
| `/` | The home page from GitHub Pages plus discovery `Link` headers (`api-catalog`, `service-desc`, `service-doc`, `describedby`, `ard`). `Accept: text/markdown` and assistants fetching for a user (`ChatGPT-User`, `Claude-User`, `Perplexity-User`…) get `/index.md` instead (`Vary: Accept, User-Agent`). Falls back to the origin if the Worker fails. |
| `/.well-known/api-catalog` | The API catalog from GitHub Pages, served as `application/linkset+json` (RFC 9727). |

The facts come from the published site at request time (`llms.txt`, `index.md`, `resume.md`, `now.md`, `blog/posts.json`, `blog/*.md`, cached for 5 minutes), so there is no second copy to keep in sync. `src/config.json` (tool names, descriptions, endpoints, Link header) is generated by `npm run generate:agents` in the repository root from `scripts/agent-config.js`; do not edit it by hand.

## Develop

```bash
cd worker
npm ci
npx wrangler dev --upstream-protocol https
```

```bash
# REST API and NLWeb
curl -s http://localhost:8787/api/now
curl -s 'http://localhost:8787/ask?query=what+is+he+doing+now'
curl -sN 'http://localhost:8787/ask?query=blog&streaming=true'

# MCP: list tools and call one
curl -s -X POST http://localhost:8787/mcp \
  -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

# A2A: ask a question
curl -s -X POST http://localhost:8787/a2a -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"message/send","params":{"message":{"kind":"message","role":"user","messageId":"1","parts":[{"kind":"text","text":"What is Iñaki Fuentes doing now?"}]}}}'
```

`wrangler dev` reads the documents from the live site, so endpoints that need files not yet published (for example `/blog/posts.json` before the first deploy) answer with a 502 problem until GitHub Pages has them.

Unit tests for the A2A, REST API and NLWeb logic (against the files on disk) and the wiring live in `tests/worker.test.js` and run with `npm test` in the repository root.

## Deploy

1. Push the site first, so GitHub Pages publishes the cards, the catalog, `openapi.json`, `index.md` and `blog/posts.json` the Worker reads and links to.
2. Then deploy the Worker (needs a `wrangler login` with access to the `ifuentes.net` zone). The deploy adds the `/api`, `/api/*` and `/ask` routes:

```bash
cd worker
npm run deploy
```

3. From the repository root, run `npm run indexnow`, and check the result at <https://isitagentready.com>.

## Optional: DNS for AI Discovery (DNS-AID)

Add this record in Cloudflare DNS for `ifuentes.net` (DNSSEC is already on):

| Type | Name | Priority | Target | Value |
| --- | --- | --- | --- | --- |
| `HTTPS` | `_index._agents` | `1` | `ifuentes.net` | `alpn="h2,h3" port=443` |
