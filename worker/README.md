# ifuentes.net agent endpoints (Cloudflare Worker)

A small Worker that runs on four paths of `ifuentes.net`. GitHub Pages keeps serving everything else.

| Path | What it does |
| --- | --- |
| `/mcp` | Read-only [MCP](https://modelcontextprotocol.io) server: Streamable HTTP, stateless, no authentication. Built with `createMcpHandler` from the [Agents SDK](https://developers.cloudflare.com/agents/model-context-protocol/apis/handler-api/). Tools `get_profile`, `get_resume`, `get_now`; the same documents as resources. |
| `/a2a` | [A2A](https://a2a-protocol.org) agent, JSON-RPC 2.0 `message/send`. Deterministic: it picks the right document and returns it verbatim, so it never invents facts. |
| `/` | The home page from GitHub Pages plus discovery `Link` headers (`api-catalog`, `service-desc`, `describedby`, `ard`). Falls back to the origin if the Worker fails. |
| `/.well-known/api-catalog` | The API catalog from GitHub Pages, served as `application/linkset+json` (RFC 9727). |

The facts come from the published site at request time (`llms.txt`, `resume.md`, `now.md`, cached for 5 minutes), so there is no second copy to keep in sync. `src/config.json` (tool names, descriptions, endpoints, Link header) is generated by `npm run generate:agents` in the repository root from `scripts/agent-config.js`; do not edit it by hand.

## Develop

```bash
cd worker
npm ci
npx wrangler dev --upstream-protocol https
```

```bash
# MCP: list tools and call one
curl -s -X POST http://localhost:8787/mcp \
  -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

# A2A: ask a question
curl -s -X POST http://localhost:8787/a2a -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"message/send","params":{"message":{"kind":"message","role":"user","messageId":"1","parts":[{"kind":"text","text":"What is Iñaki Fuentes doing now?"}]}}}'
```

Unit tests for the A2A logic and the wiring live in `tests/worker.test.js` and run with `npm test` in the repository root.

## Deploy

1. Push the site first, so GitHub Pages publishes the cards and the catalog the Worker links to.
2. Then deploy the Worker (needs a `wrangler login` with access to the `ifuentes.net` zone):

```bash
cd worker
npm run deploy
```

3. From the repository root, run `npm run indexnow`, and check the result at <https://isitagentready.com>.

## Optional: DNS for AI Discovery (DNS-AID)

Add this record in Cloudflare DNS for `ifuentes.net` (DNSSEC is already on):

| Type | Name | Priority | Target | Value |
| --- | --- | --- | --- | --- |
| `HTTPS` | `_index._agents` | `1` | `ifuentes.net` | `alpn="h2,h3" port=443` |
