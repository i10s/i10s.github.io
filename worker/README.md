# ifuentes.net (Cloudflare Worker)

The Worker serves all of `ifuentes.net`: the static site (the repository root as [static assets](https://developers.cloudflare.com/workers/static-assets/), minus what `../.assetsignore` lists) and the agent endpoints below. It runs first on every request (`src/site.js`):

- **Paths** resolve as on GitHub Pages, so URLs did not change: `/dir/` → `/dir/index.html`, `/page` → `/page.html`, `/dir` → 301 `/dir/`, anything else → `/404.html` with a 404.
- **Security headers** on every response: `Content-Security-Policy`, `X-Frame-Options: DENY`, `Referrer-Policy`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`, `X-Content-Type-Options`. HSTS (one year, `includeSubDomains`, `preload`) and TLS 1.2+ are zone settings, so they also cover the other subdomains.
- **`www.ifuentes.net`** redirects (301) to the apex, keeping path and query.
- **`mta-sts.ifuentes.net/.well-known/mta-sts.txt`** serves the MTA-STS policy (`mode: enforce`, Proton MX hosts). If the MX hosts change, update `MTA_STS_POLICY` and the `id` of the `_mta-sts` TXT record.

| Path | What it does |
| --- | --- |
| `/api`, `/api/*` | Read-only REST API (`src/api.js`): `/api` (index), `/api/profile`, `/api/resume`, `/api/now` (JSON with the Markdown text and its `last_updated`), `/api/posts` (`?topic=`, `?lang=`, `?limit=`) and `/api/posts/{slug}`. CORS `*`, `GET`/`HEAD`/`OPTIONS`; errors are RFC 9457 `application/problem+json` (400, 404, 405, 502). Described by `/openapi.json`. |
| `/mcp` | Read-only [MCP](https://modelcontextprotocol.io) server: Streamable HTTP, stateless, no authentication. Built with `createMcpHandler` from the [Agents SDK](https://developers.cloudflare.com/agents/model-context-protocol/apis/handler-api/). Tools `get_profile`, `get_resume`, `get_now`, `get_blog_posts` (the same documents as resources) and `get_blog_post` (`slug`). |
| `/a2a` | [A2A](https://a2a-protocol.org) agent, JSON-RPC 2.0 `message/send`. Deterministic: it picks the right document and returns it verbatim, so it never invents facts. |
| `/ask` | [NLWeb](https://github.com/nlweb-ai/NLWeb) v0.55 (`src/nlweb.js`), list mode: `GET ?query=` or `POST {"query":{"text":…}}`; `streaming=true` or `Accept: text/event-stream` for server-sent events (`start`, `result`, `complete`). Ranks the documents with the A2A keyword rules and the blog posts by the words of their title and summary; no generative AI. |
| `/` | The home page plus discovery `Link` headers (`api-catalog`, `service-desc`, `service-doc`, `describedby`, `ard`). `Accept: text/markdown` and assistants fetching for a user (`ChatGPT-User`, `Claude-User`, `Perplexity-User`…) get `/index.md` instead (`Vary: Accept, User-Agent`). Falls back to the plain home page if that fails. |
| `/.well-known/api-catalog` | The API catalog, served as `application/linkset+json` (RFC 9727). |

The facts come from the published files at request time (`llms.txt`, `index.md`, `resume.md`, `now.md`, `blog/posts.json`, `blog/*.md`, read through the `ASSETS` binding), so there is no second copy to keep in sync. `src/config.json` (tool names, descriptions, endpoints, Link header) is generated by `npm run generate:agents` in the repository root from `scripts/agent-config.js`; do not edit it by hand.

## Develop

```bash
cd worker
npm ci
npx wrangler dev
```

```bash
# REST API and NLWeb
curl -s http://localhost:8787/api/now
curl -s 'http://localhost:8787/ask?query=what+is+he+doing+now'
curl -sN 'http://localhost:8787/ask?query=blog&streaming=true'

# MCP: list tools and call one
curl -s -X POST http://localhost:8787/mcp \
  -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

# A2A: ask a question
curl -s -X POST http://localhost:8787/a2a -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"message/send","params":{"message":{"kind":"message","role":"user","messageId":"1","parts":[{"kind":"text","text":"What is Iñaki Fuentes doing now?"}]}}}'
```

`wrangler dev` serves the files on disk, so run `npm run build` in the repository root first if you changed the sources.

Unit tests for the A2A, REST API and NLWeb logic (against the files on disk) and the wiring live in `tests/worker.test.js` and run with `npm test` in the repository root.

## Deploy

1. The **Deploy Worker** workflow (`.github/workflows/deploy-worker.yml`) deploys the site and the Worker after the tests pass on every push to `main`, using the `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` secrets of the personal account that owns the `ifuentes.net` zone. To deploy by hand from a clean checkout (everything in the root not listed in `.assetsignore` is published, untracked files included):

```bash
cd worker
npm run deploy
```

2. From the repository root, run `npm run indexnow`, and check the result at <https://isitagentready.com>.

## Optional: DNS for AI Discovery (DNS-AID)

Add this record in Cloudflare DNS for `ifuentes.net` (DNSSEC is already on):

| Type | Name | Priority | Target | Value |
| --- | --- | --- | --- | --- |
| `HTTPS` | `_index._agents` | `1` | `ifuentes.net` | `alpn="h2,h3" port=443` |
