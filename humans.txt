# DESIGN

    Concept: "Departures". A split-flap airport board for a career in travel tech.
    Departures = what I do now. Arrivals = where I have been.
    Palette: airport signage yellow (#ffcc00), board black, paper.
    Type: system UI sans + system monospace. No web fonts.
    Motion: one flap on load, nothing looping. Off with prefers-reduced-motion.
    Easter egg: try the Konami code on the home page.

# TECHNOLOGY COLOPHON

    Standards: HTML5, CSS3, JSON-LD, RSS 2.0
    Components: Progressive Web App (PWA), Service Worker, Web Vitals
    Testing: Mocha, Chai, JSDOM, html-validate (199 automated tests)
    CI/CD: GitHub Actions, Lighthouse CI
    Software: VS Code, Git, Node.js
    Fonts: System fonts (system-ui, ui-monospace)
    Performance: Inline CSS, one shared 5KB script (flap.js), zero dependencies
    Accessibility: WCAG 2.1 AA + AAA (high contrast) compliant
    Development: Live reload dev server, pre-commit validation
    
# OPTIMIZATION

    Page weight budget: ≤35KB total per page (HTML + same-origin JS/CSS + images)
    Load time: <500ms (LCP)
    Lighthouse score: 100/100 (all categories)
    Carbon footprint: Minimal (green hosting, static site)
    Hosting: GitHub Pages (global CDN, static caching)
    Security: Zero vulnerabilities, CSP headers, HTTPS only
    
# ARCHITECTURE

    Responsive: Mobile-first, fluid typography with clamp()
    Dark Mode: Automatic via prefers-color-scheme
    High Contrast: WCAG AAA via prefers-contrast
    Offline: Service Worker with cache-first strategy
    Monitoring: Real-time Web Vitals (CLS, LCP, FID, INP, FCP, TTFB)
